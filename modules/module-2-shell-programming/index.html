Shell Programming

Learn how shells work and use command-line tools, filters and scripting utilities to automate tasks.

// MODULE CONTENTS

Topics covered

  1. Need for shells and shell types
  2. Derived operators and Linux sessions
  3. Standard streams, redirection, pipes and tee
  4. Command execution and command-line editing
  5. Quotes, substitution, job control and aliases
  6. Variables and environment customization
  7. Filters, pipes and file operations
  8. Grep, sed and AWK
