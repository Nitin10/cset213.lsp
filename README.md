# CSET213: Linux and Shell Programming

Official course portal containing the course roadmap, slides, assignments, videos, reference materials, announcements and instructor profiles.

## Administrating the website

- Edit `index.html` to update course content and links.
- Edit `styles.css` to adjust presentation.
- Upload materials into clearly named folders such as `slides/`, `assignments/`, `videos/` and `references/`.
- Use relative links, for example: `slides/module-1.pdf`.

GitHub Pages deployment runs automatically after every change to the `main` branch.
