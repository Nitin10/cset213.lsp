Objectives, Outcomes
& Course Contents

Linux and Shell Programming · CSET213 · 30 contact hours

// COURSE OBJECTIVES

Students will gain practical and conceptual foundations.

  1. Develop hands-on competence in installing and setting up the Linux operating system on desktops and laptops.
  2. Introduce essential Linux commands and familiarize students with working through the command-line terminal.
  3. Explain the essential ideas behind the open-source operating-system approach to programming.
  4. Nurture knowledge of Linux, shell scripts, AWK scripts and network-scanning tools that support understanding of the cybersecurity backbone.
  5. Introduce shell scripting, file structure and management, processes, inter-process communication, socket programming and security.

// COURSE CONTENTS

Four-module learning journey.

I
8 CONTACT HOURS

Linux Fundamentals

Linux and Linux utilities; architecture and features of Linux; introduction to the vi editor; Linux commands; file-handling utilities; security through file permissions; process, disk, networking, text-processing and backup utilities; and user management.

II
8 CONTACT HOURS

Shell Programming

Need for shells and shell types; derived operators; Linux sessions; standard streams; redirection; pipes; tee command; command execution and command-line editing; quotes; command substitution; job control; aliases; variables; shell and environment customization; filters and pipes; file operations; grep operations, commands, addresses and applications; sed scripts and operations; and AWK.

III
8 CONTACT HOURS

System Files and Processes

Unix file structure; file descriptors; system calls and device drivers; file management and structures; system calls for file management; directory API; processes and process structure; process table; viewing processes; system processes and scheduling; zombie and orphan processes; fork and its operation; signal functions; unreliable signals; interrupted system calls; signal sets; file locking; sockets and socket communication; UDP; and TCP.

IV
6 CONTACT HOURS

Threat Analysis Tools

Threat and vulnerability analysis of Linux: direct, indirect, veiled and conditional threats; Linux security measures including SSH key pairs, log-file scanning and closing hidden ports; Linux malware including botnets, ransomware and rootkits; shell scripting and security through password testing, permissions and access-control lists; Docker container configuration; and shell scripting for DevOps and Site Reliability Engineering workflows.
