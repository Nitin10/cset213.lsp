// COURSE OVERVIEW

Learn Linux by
doing real work.

This course combines clear concepts with guided terminal practice. Students learn to navigate Linux, manage a system, process text and automate repetitive tasks using shell scripts.

No previous Linux experience is required—just curiosity and a willingness to experiment.
